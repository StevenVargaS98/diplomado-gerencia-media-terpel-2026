# Brújula Estratégica — GitHub Pages

Versión estática demostrativa, lista para alojarse gratuitamente en GitHub Pages.

## Publicar

1. Cree un repositorio nuevo en GitHub.
2. Cargue **el contenido de esta carpeta** en la rama `main`.
3. En el repositorio abra **Settings → Pages**.
4. En **Build and deployment**, seleccione **Deploy from a branch**.
5. Seleccione la rama `main`, carpeta `/ (root)` y pulse **Save**.
6. Espere uno o dos minutos. GitHub mostrará la URL publicada.

No requiere instalación, compilación ni dependencias.

## Importante

GitHub Pages solo publica archivos estáticos. Por eso esta edición guarda la información en el navegador con `localStorage`: permite probar el acceso y las interacciones, pero los datos no se comparten entre computadores.

Para colaboración real se debe publicar la versión `brujula-web` con una base D1, Supabase o Firebase. Las credenciales incluidas aquí son exclusivamente demostrativas y son visibles dentro del código fuente.
